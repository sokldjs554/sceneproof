# ERGO 논문 읽기와 SceneProof 적용

**논문:** Jewon Lee 외, *ERGO: Efficient High-Resolution Visual Understanding for Vision-Language Models*, ICLR 2026. [논문 원문](https://openreview.net/pdf/0e0a5a663137f946cbc9c8cbeafd1190961a63cd.pdf)

## 1. 풀려는 문제

고해상도 이미지를 한꺼번에 자세히 처리하면 시각 토큰이 늘어나 추론 비용이 커진다. 반대로 화면 전체를 작게 줄이면 질문에 필요한 작은 대상과 세부 정보가 사라질 수 있다. ERGO는 적은 비용으로 질문에 필요한 부분을 자세히 살피는 방법을 다룬다.

## 2. 핵심 방법

먼저 축소한 이미지와 질문을 바탕으로 모델이 답에 필요한 영역의 좌표를 고른다. 이어서 선택한 영역을 원본 해상도에서 잘라 다시 보고 답을 생성한다. 영역 선택은 강화학습으로 학습하며, 잘린 영역만으로 정답을 얻을 수 있는지 확인하는 보상과 지나치게 넓은 영역을 고르지 않도록 하는 보상을 함께 사용한다. 정답과 출력 형식에 대한 보상도 함께 적용한다. 핵심은 대상의 위치뿐 아니라 질문에 답하는 데 필요한 주변 맥락까지 고르는 것이다.

## 3. 실험에서 본 것

논문 표 3의 V* 벤치마크에서 고해상도 원본 모델과 ERGO를 비교한 예다. 평균 시각 토큰 수는 전체 추론에 사용된 값이다.

| 비교 대상 | 입력 픽셀 제한 | V* 점수 | 평균 시각 토큰 |
|---|---:|---:|---:|
| Qwen2.5-VL-7B 기본 모델 | 16,384 × 28 × 28 | 77.0 | 4,471 |
| ERGO | 640 × 28 × 28 | 81.7 | 1,025 |

이 비교에서 ERGO는 점수가 4.7점 높고 시각 토큰은 약 23%였다. 즉 논문 조건에서는 질문에 필요한 영역을 선택하는 방식이 적은 토큰으로도 좋은 결과를 보였다. 기본 모델과 입력 픽셀 제한이 다르며, 이 결과를 다른 모델이나 현장 장면에 그대로 적용할 수는 없다. 논문 표 4에서 같은 두 설정의 평균 지연은 각각 4.89초와 1.61초였다.

## 4. 한계와 의문

1. 축소된 전체 화면에서 필요한 영역을 잘못 고르면 이후 단계에 중요한 정보가 전달되지 않을 수 있다. 사람 상자나 구역 좌표가 정확하지 않은 현장 영상에서는 얼마나 안정적일까?
2. 논문 결과는 Qwen 계열 모델과 특정 고해상도 VQA 벤치마크의 결과다. CPU에서 동작하는 SmolVLM과 발·구역 관계 판단에서도 같은 경향이 나타나는지 별도 검증이 필요하다.
3. 영역을 작게 만드는 것이 항상 유리하지 않다. 발만 확대하면 구역의 전체 형태나 어느 쪽이 내부인지 판단하는 데 필요한 맥락이 사라질 수 있다.

## 5. SceneProof에 적용한다면

검토 서버가 전체 장면을 SmolVLM에 보내는 대신, 추적된 사람 상자와 발에서 가장 가까운 구역 경계를 함께 포함하는 영역을 보내도록 실험한다. 같은 질문과 장면을 사용해 전체 화면 한 조각(`full`), 전체 화면 분할(`split`), 선택 영역 한 조각(`crop`)을 비교한다. 안·밖별 정답, 보류·형식 오류, 시각 토큰, 지연 중앙값과 영역 크기를 측정하고, 잘못 답한 입력 이미지를 원본과 대조한다. 실제 사람과 상자의 정합성, 실제 발 위치를 별도 검수해야 결과를 해석할 수 있다.

## 6. 실행한 실험

사람 상자와 구역 경계로 자르는 규칙을 적용하고, 진입·머무름 장면 23장에 원래 구역과 옮긴 구역을 각각 그려 **46문항 × 3가지 방식**을 비교했다. 정답은 `full` 19/46, `split` 9/46, `crop` 8/46이었다. `crop`은 24문항에서 답을 보류했다. 이탈 장면은 저장된 사람 상자가 실제 프레임의 사람 위치와 어긋나는 사례가 있어 평가에서 제외했다.

정답은 사람 상자 아래 중앙 좌표를 기준으로 만들었으므로 실제 발을 사람이 표시한 정답과 같다고 단정할 수 없다. 이 작업은 ERGO의 모델이나 학습 재현이 아니라 문제의식에서 출발한 별도 적용 실험이다. 설정과 장면별 검토는 [실험 보고서](README.md)에 있다.
