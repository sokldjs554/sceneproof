# 작은 VLM 입력 영역 비교: 46문항 결과

## 무엇을 비교했나

같은 질문에 대해 SmolVLM-500M-Instruct가 세 방식으로 본 화면을 비교했다. `full`은 전체 화면 한 조각, `split`은 전체 화면을 여러 조각과 전체 보기로, `crop`은 사람 상자와 발 좌표에 가장 가까운 구역 경계를 포함하는 영역 한 조각을 보낸다.

데모 **15건의 사건, 카메라 2대**에서 진입·머무름 근거 장면 23장을 골랐다. 각 장면에 원래 구역과 옮긴 구역을 각각 그려 **안 23문항, 밖 23문항**을 만들었다. 옮긴 구역은 실제 관측된 장면이 아닌 통제된 대조군이다. 이탈 장면은 저장된 사람 상자가 실제 프레임 속 사람보다 뒤처진 사례가 확인되어 제외했다. 나머지 장면에서도 상자와 실제 발의 정합성을 모두 검증한 것은 아니다.

정답은 **사람 상자 아래 중앙 좌표**의 구역 포함 여부로 생성했다. 실제 발 위치를 사람이 표시한 정답이 아니다. 같은 이미지에서 나온 원래·이동 구역은 서로 독립적인 장면이 아니다. 46문항에 대한 결과이지 46개 사건의 결과가 아니다.

## 치우침의 원인을 가르는 다음 실험 — 아직 실행하지 않음

1. **평가셋 정리:** 사람과 상자가 맞는지, 발이 보이는지, 발과 경계가 충분히 떨어져 있는지 사람이 원본·crop 쌍을 보고 검수한다. 명확한 안·밖과 경계·가림을 나누고 두 명의 판정을 비교한다. 같은 원본에서 나온 쌍은 함께 묶어 분석한다.
2. **질문만 바꾸기:** 이미지·모델·생성 설정을 고정하고 기존 질문, 간결한 질문, 빨간 음영과 노란 상자 의미를 명시한 질문을 같은 쌍에 적용한다. 안/밖별 정답, 보류·형식 오류와 쌍별 변화량을 비교한다. 질문에 따라 같은 모델의 결과가 크게 달라지면 질문 민감성을 의심할 수 있다.
3. **모델만 바꾸기:** 이미지·질문·평가기준을 고정하고 더 큰 모델 또는 다른 모델을 비교한다. 여러 질문에서도 작은 모델만 명확한 사례를 일관되게 틀리고 다른 모델이 맞힌다면 모델 역량 차이 가능성이 커진다. 한 번의 비교만으로 원인을 확정하지 않는다.
4. **맥락만 바꾸기:** 같은 사람·구역으로 현재 crop, 넓힌 crop, 전체 화면을 비교하고 필요한 경우 선만 보이는 경우와 내부 영역이 충분히 보이는 경우를 별도로 점검한다. 각 방식의 실제 픽셀·토큰과 지연도 함께 기록한다. 정답에 맞춰 사후적으로 여백을 고르지 않는다.

## 결론과 한계

이번 46문항에서는 선택 영역을 보내는 방식이 전체 화면보다 정확하지 않았고 보류도 많았다. `split`도 `full`보다 정답이 적었다. 특히 안쪽 정답은 세 방식 모두 거의 맞히지 못했다. 따라서 현재 자료만으로 crop이 모델 성능을 높였거나, 특정 원인이 편향을 만들었다고 주장할 수 없다.

자료는 **사건 15건, 카메라 2대, 작은 모델 하나**에 한정된다. 23개 원본 장면과 옮긴 구역 대조군은 실제 현장의 다양한 배치를 대표하지 않는다. 정답은 상자 좌표의 기하학적 판정이고 발 가림과 경계 상황이 있어, 사람 기준으로 명확한 사례를 다시 선정한 비교가 필요하다. 논문의 학습된 영역 선택이나 강화학습을 재현한 결과는 아니다.
