# 노란 상자 속 사람의 양쪽 발이 모두 보이는가?

SmolVLM-500M은 23장 모두에 `No.`라고 답했다. 양쪽 발을 확인할 수 있는 12장을 전부 놓쳤고, 한쪽 이상 보이지 않는 11장은 맞혔다. 이번 질문에서는 모든 답을 문제없이 읽을 수 있었지만, 답이 장면에 따라 달라지지 않았다.

## 질문과 기준 답

같은 15건의 사건, 카메라 2대에서 기존 실험의 진입·머무름 프레임 23장을 한 번씩 사용했다. 원래 구역과 옮긴 구역은 발의 가시성이 같은 사진이므로 중복시키지 않았다. 원본 근거 사진에 대상 식별용 노란 사람 상자만 그리고 화면 전체를 입력했다. 상자 밖으로 조금 나온 신발도 같은 사람의 것으로 식별할 수 있으면 포함했다.

> Look at the person in the yellow box. Are both of their feet visible in this image? Answer yes or no.

모델을 실행하기 전에 23장 전체를 열어 보았다. 양쪽 발 또는 신발을 각각 식별할 수 있으면 `yes`, 한쪽 이상이 화면 밖이거나 가려서 식별할 수 없으면 `no`로 기록했다. 경계에 걸쳐 일부만 보이는 발도 어느 발인지 식별할 수 있으면 보인 것으로 셌다. 이 기준 답은 한 번의 이미지 판독으로 정했으며 독립 검수자는 없었다. 답변은 대소문자와 끝의 마침표·느낌표를 허용한 단일 yes/no로 채점했다. [사전 기준 답](labels.json) · [문항별 모델 응답](result.json)

| 이미지 판독 | 장면 수 | 모델 Yes | 모델 No |
|---|---:|---:|---:|
| 양쪽 발이 보임 | 12 | 0 | 12 |
| 한쪽 이상 보이지 않음 | 11 | 0 | 11 |

개별 정답은 **11/23 (47.8%)**였다. 항상 다수 답인 Yes를 고르면 **12/23 (52.2%)**다. 예를 들어 `06c0e0fd` 진입 장면에서는 상체만 보이고 머무름 장면에서는 양쪽 신발이 나란히 보인다. 모델은 두 사진에 똑같이 No라고 답했다. [진입 원본](../../../demo/bundle/evidence/06c0e0fd-f35b-506d-ad77-322685106b58/entry.jpg) · [머무름 원본](../../../demo/bundle/evidence/06c0e0fd-f35b-506d-ad77-322685106b58/dwell.jpg)

이번 자료에서 기준 답이 No인 11장은 모두 적어도 한쪽 발이 화면 아래로 나간 경우다. 상자가 화면 경계와 가까워도 두 신발의 일부를 모두 식별할 수 있는 예외가 있다(`aeed2100` 진입). 사진 판독 뒤 탐색적으로 비교한 단순 규칙도 이 편중을 보여 준다. 상자 하단이 화면 높이의 마지막 5%에 걸리면 No로 답하는 규칙은 22/23장을 맞혔다. 이 규칙은 별도 검증 자료에서 평가하지 않았다. 따라서 화면 밖 잘림과 물체에 의한 가림을 구분하는 성능, 다른 카메라에서의 성능은 별도 평가가 필요하다. 위치 관계와 발 가시성은 정답 기준과 문항 수가 달라 두 점수의 차이를 개선량으로 계산할 수 없다.

## 재현

저장소 루트에서 원래 실험과 같은 가중치·생성 설정을 사용한다. 전체 화면 한 장, 시각 토큰 64개, CPU 2스레드, greedy decoding이다.

```bash
PYTHONPATH=src python docs/experiments/foot-visibility/run.py
```
