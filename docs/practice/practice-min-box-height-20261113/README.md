# 과제 3: 최소 사람 상자 높이 40px 실험

- 네 평가 영상에서 기본 설정과 40px 설정의 정답 연결 사건은 모두 12건, 놓친 사건은 0건, 중복 사건은 6건이었다. 이 실행에서는 새로 놓친 사람이 없었다.
- 영상마다 30프레임을 균등 추출해 기본 탐지 상자를 따로 확인한 결과, 캠퍼스 영상의 168개 중 4개가 40px 미만이었다. 실험 설정이 작은 상자를 실제로 제외할 수 있어도 사건 단위 집계는 같을 수 있다.
- 주차장 영상에서 기본 설정을 두 번, 40px 설정을 한 번 추가 실행했다. 각 설정 내의 사건 시각이 재현되고 설정 사이에 같은 종료 시각 차이가 나타나, 이 실험에서의 차이는 40px 필터 설정에 따른 것으로 확인했다.

| 영상 | 정답 연결: 기본 → 40px | 놓침: 기본 → 40px | 중복: 기본 → 40px | 종료 시각 MAE: 기본 → 40px |
| --- | ---: | ---: | ---: | ---: |
| eval-campus | 4 → 4 | 0 → 0 | 2 → 2 | 1.35초 → 1.35초 |
| eval-indoor | 4 → 4 | 0 → 0 | 0 → 0 | 0.24초 → 0.24초 |
| eval-store | 1 → 1 | 0 → 0 | 3 → 3 | 23.43초 → 23.43초 |
| eval-parking | 3 → 3 | 0 → 0 | 1 → 1 | 1.69초 → 1.33초 |

주차장 영상의 예측 사건 시작 26.25초는 종료 26.67초 → 28.17초, 시작 44.58초는 종료 45.75초 → 45.33초로 달랐다. 수치는 초 단위 반올림이다. 그 외 사건 집계의 동일함을 모든 예측이 동일하다는 뜻으로 해석하면 안 된다.

## 주차장 재실행 확인

주차장 기본 설정 결과의 사건 네 건은 세 번 모두 시작·종료 시각과 체류 판정이 같았다. 40px 설정도 두 번 모두 같았고, 두 설정 간에는 위 두 사건의 종료 시각 차이가 반복됐다. 입력 영상과 모델의 SHA-256을 다시 확인했고, 다섯 실행 모두 647프레임을 처리했다. 이는 같은 입력과 환경에서 설정이 결과를 바꾼다는 근거다. JSON 파일 전체가 바이트 단위로 동일하다는 뜻은 아니다. 실행 시간, 처리 시간, 사건 ID 등은 실행마다 달라질 수 있다.

추가 실행 원본은 `parking-base-repeat.json`(기록 항목 보완 전), `parking-base-audit.json`(보완 후 0px), `parking-min40-repeat.json`(보완 후 40px)이다. 보완 후 두 결과의 `per_video.eval-parking.run.detector.min_box_height_px`는 각각 0과 40으로 기록됐다.

주차장 25~29초와 43~47초를 3프레임 간격으로 표본 조사했다. 44.75초에는 화면에 맞춰 자른 뒤의 높이가 23.2px인 탐지 상자가 있었다. `parking_box_check.py`와 `parking-box-check.txt`에 표본의 좌표, 높이와 점수를 남겼다. 이 상자를 특정 사건의 자전거 탑승자로 확인하지는 않았으며, 어떤 상자와 추적 상태가 종료 시각을 바꿨는지는 별도로 추적하지 않았다.


기본 결과 `base.json`은 과제 2에서 실행한 0.3초 기준 결과를 재사용했고, `min40.json`은 이번 결과다. 두 YAML 설정을 대조해 `detector.min_box_height_px=40`만 다른 것을 확인했다. 두 실험은 YOLOX Tiny ONNX CPU, Python 3.12.14, OpenCV 5.0.0, NumPy 2.3.5, ONNX Runtime 1.31.1, 동일한 평가 영상과 모델을 사용했다. 모델 및 영상 SHA-256은 [과제 2 기록](../practice-entry-confirm-20261113/README.md)에 있다. 실험 결과 파일의 Git 식별자는 작업공간 로컬 HEAD `aad33d0`이며 두 실행 모두 작업 트리에 미커밋 변경이 있었으므로 해당 커밋의 깨끗한 트리에서 실행한 결과가 아니다.

샘플 조사에서 캠퍼스·실내·매장·주차장 각 30프레임의 기본 탐지 상자 수는 각각 168·21·95·8개였고, 40px 미만은 4·0·0·0개였다. 전체 영상의 탐지 상자 집계가 아니다. `sample_boxes.py`는 균등 추출 및 집계 코드다.
