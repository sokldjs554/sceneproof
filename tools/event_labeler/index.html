표시 방법
  1. 사람의 발이 빨간 구역 안에 들어간 순간 I, 구역에서 나온 순간 O를 누릅니다. 한 사람이 들어갔다 나오면 사건 1건입니다.
  2. 여러 사람이 동시에 들어가면 사람마다 따로 I를 누르고, 나올 때 목록에서 그 사람 줄의 "나감" 버튼을 누릅니다.
  3. 발이 선 위를 스치기만 했으면 B(경계 통과), 확신이 없으면 U(불확실)로 바꿉니다.
  4. 다른 사람의 결과를 보지 말고 혼자 표시한 뒤 내보내기로 저장하세요. 두 사람의 파일을 비교합니다.
